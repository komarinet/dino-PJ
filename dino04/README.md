# REX RESCUE｜ティラノと約束の島（dino04）

スマートフォン縦持ちで遊ぶ、全3ステージの3D恐竜アクション。
ChatGPT Sites版から移し、下部の操作デッキ・画面・カメラを縦持ち向けに調整しました。

## 公開と復元

- GitHub Pagesでは、このリポジトリのmainブランチの / (root) を公開します。
- 入口はdino04/index.html。リポジトリ直下のゲーム広場からも開けます。
- コード、Three.js、効果音を同梱しています。ChatGPTのログイン・API・Sitesは不要です。
- ビルドとnpmインストールは不要。フォルダ構成を保って一般の静的Webホスティングへコピーすれば公開できます。
- ローカル確認はリポジトリ直下で `python3 -m http.server 8000` を実行し、`http://localhost:8000/dino04/` を開きます。ES Modulesと音声読み込みを使うため、file://での直開きは避けてください。

## 操作

左スティック：移動。右：ジャンプ・とっしん・かみつく・なかま。
右上：一時停止と効果音のオン・オフ。
PC：WASD・矢印、Space、J、K、L、Esc。

縦持ちを標準に下部へ操作専用スペースを確保し、セーフエリアとブラウザの可変高さに対応。
PCでは中央に表示、横持ちにも簡易対応します。

## 素材

恐竜・地形・植物はゲーム内で生成する3Dメッシュで、画像ファイルはありません。
効果音7種類は22.05 kHz・モノラルのOgg Vorbisで、合計約28 KBです。BGMは未実装。
Three.js r170はassets/three.module.jsに同梱。MITライセンスはTHREE-LICENSE.txtを参照。
今後の画像追加はWebP、音声追加はOGGを基本とします。
ASSETS.jsonには配信ファイルのサイズと検証用ハッシュを記録しています。

## セーブと更新

進行状況と効果音設定は端末・ブラウザ・公開元ごとのlocalStorageに保存します。
Sites版のセーブはGitHub Pagesへ自動移行されません。ブラウザのデータを消去するとセーブも消えます。
GitHubの更新はPagesへ反映されますが、Sitesでの編集はこのフォルダへ自動同期されません。
Sites側を更新したときは変更したコードと素材をGitHubにも保存し、公開版を確認してください。

## 検証

JavaScript構文、移動・ジャンプ・一時停止・全3章の進行・両方の鉄柵・救出エンディングのロジックを確認。
360×740の縦画面で、全操作ボタンとスティックが画面内に収まることを確認。
制作環境のブラウザではWebGLが利用できず、3D描画とフレームレートは実機Chromeでの確認が必要です。
